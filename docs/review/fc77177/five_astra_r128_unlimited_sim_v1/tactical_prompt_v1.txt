## 可用 MCP 工具（kimiark-r128-unlimited-sim）
- `get_session_status` — 元信息与已跑次数。
- `list_parents` — 两个父方案的完整动作。
- `run_simulation` — 提交 `{actions:[...], selected:[...], label?}`。`actions` 是 `{action_type, frame, operator_id, tile?, direction?}` 数组，frame 是 30fps 帧号，tile 是 `[row,col]`，direction 是 `UP|DOWN|LEFT|RIGHT`。返回完整 summary + 全部事件。**没有预算限制**，但每次调用是完整 600 秒模拟（~4 秒真实耗时），不要瞎扫几万帧。
- `query_events` — 按 `run_id` / `event_type` / `source_id` / `target_id` / `earliest_frame` / `latest_frame` 过滤，或 `aggregate_field`（如 `"amount"`）聚合伤害。
- `inspect_file` — 读仓库文件（py/json/md/txt，≤200 行）。

## 关键机制事实（R125 修复后生效，均已实测）
- **再部署费用惩罚**：第二次部署费用 = 原费用 × 1.5（floor），第三次 × 2.0；死亡返 0，普通撤退返 `floor(min(paid,base)×0.5)`，冲锋手全额。
- **敌人受击半径 0.1**（KB-BILI-002），敌人命中判定用实体坐标对 covered tile 并集，不再是取整格。
- **敌方远程仇恨**：候选按最后部署的干员优先（`deploy_sequence` 最大）。
- **3 帧阻挡扫描**：角色每 3 帧（30fps 下每 0.1s）扫描一次阻挡，但扫描窗口覆盖自上次扫描以来的全部位移（R127 修复），不会漏检。
- **惯性记录**：敌人有 `inertia_velocity`，沿路线方向 steering（地面 8/10、飞行 20/100）。
- 炮兵空等语义已加回归守卫（`390bf15f`）。
